# M1 — Tool installation

**Roadmap:** [ROADMAP.md](../ROADMAP.md) · **Spec:** [build-plan.md](../build-plan.md) §9, §22 (M1), §18 (tests 1–5)

## Goal

On startup, when Infinity Hammer is present and integration is enabled, install **only** SonicWorldTools-owned tool YAML into `BepInEx/config/tools/infinity_tools_sonicworldtools.yaml`, expose **Precision Area Pipette** in Infinity Hammer’s existing Hammer tools menu, and route the tool command to a controller entry point (selection logic comes in M3).

## Deliverables

| Path | Purpose |
|------|---------|
| `src/SonicWorldTools/Core/ToolInstaller.cs` | Detect tools directory, create/update generated YAML, versioning & conflict rules |
| `assets/infinity_tools_sonicworldtools.yaml` | Source template embedded or copied at build time |
| `src/SonicWorldTools/Modules/PrecisionAreaPipette/PrecisionAreaPipetteCommand.cs` | Register/handle `sonic_precision_pipette` (or name matching YAML `command`) |
| `src/SonicWorldTools/Modules/PrecisionAreaPipette/PrecisionAreaPipetteController.cs` | Minimal activate/deactivate lifecycle when tool is selected (no box selection yet) |
| `Plugin.cs` | Call `ToolInstaller` after dependency detection when `[Integration] InstallInfinityHammerTools = true` |

**Generated file on disk (runtime):**

```text
BepInEx/config/tools/infinity_tools_sonicworldtools.yaml
```

Content per build plan §9:

```yaml
# Generated by SonicWorldTools
# Template-Version: 1
hammer:
  - name: Precision Area Pipette
    description: |-
      Select an exact rectangular volume using two corners.
      Refine the selection before copying.
    icon: hammer
    command: sonic_precision_pipette
    instant: true
```

Validate `instant: true` in-game during M1/M6; adjust only if IH behavior requires it.

**ToolInstaller upgrade logic (§9):**

- Create file if missing.
- Replace if existing file is an **untouched** old generated file (match header + Template-Version).
- **Preserve** user-modified file (detect via marker or hash of template body).
- On conflict with outdated generated content, write `infinity_tools_sonicworldtools.yaml.new` and log — do not overwrite user edits.

Log on success: `[SonicWorldTools] Installed Precision Area Pipette tool definition.` (§14).

## Acceptance criteria

From build plan §22 — **Milestone 1**:

- Generated Infinity Hammer YAML with safe update logic.
- Tool appears in Hammer menu.
- Command activates controller.

**Acceptance:** Tool can be **selected repeatedly without duplicates** or duplicate menu entries.

In-game regression (§18, items 1–5):

1. SonicWorldTools + Infinity Hammer installed; launch game.
2. No new physical Hammer item required (one Hammer — §2).
3. **Precision Area Pipette** appears in Hammer tool menu.
4. Built-in Pipette, Building Pipette, and Area Pipette still work.
5. Selecting Precision Area Pipette activates Sonic controller (log or visible state); deselecting another IH tool leaves Sonic inactive.

## Non-goals / do-not

- Do not edit `infinity_tools.yaml` or any non-SonicWorldTools YAML (§2, §9).
- Do not implement corner selection, preview, or hand-off (M3–M5).
- Do not add a custom Hammer item or second build menu (§2, §23).
- Do not patch Infinity Hammer for menu injection — use additive `infinity_tools*.yaml` loading (§3).

## Start-here checklist (implementing agent)

1. Confirm M0 complete: plugin loads, `DependencyDetector` reports IH status.
2. Read Infinity Hammer upstream: `ToolManager` loads `infinity_tools*.yaml` (§3, §26).
3. Implement `ToolInstaller` with unit tests per §16 (YAML installer cases) — can live in `tests/SonicWorldTools.Tests/ToolInstallerTests.cs`.
4. Embed template from `assets/infinity_tools_sonicworldtools.yaml`; write only to `infinity_tools_sonicworldtools.yaml`.
5. Wire IH command `sonic_precision_pipette` to `PrecisionAreaPipetteController` (activate flag only).
6. Deploy with `..\tools\dev.ps1 deploy`; use Infinity Hammer YAML hot-reload if available, else restart once.
7. Verify menu + repeated selection; verify default pipettes unchanged.
8. Proceed to [M2-selection-engine.md](M2-selection-engine.md).
